Нода Remnawave под ключ. Одной командой.

Свежий сервер → firewall, SSL, Docker, remnanode, тюнинг сети — и нода уже в панели. Снаружи она выглядит обычным сайтом.

sudo bash -c "$(curl -fsSL https://raw.githubusercontent.com/juhnsooqa/meridian/main/meridian.sh)"

Под root, нужен домен с A-записью на IP сервера. Сразу полная установка — добавь -- full. Дальше на сервере есть команда meridian: она всегда берёт свежую версию.

Что делает full

Шесть шагов подряд. На первой ошибке — стоп с понятной причиной, а не полуживая нода.

  1. Вход в панельAPI-токен, SECRET_KEY
  2. Firewallпорт ноды → панель
  3. nginx + SSLLet's Encrypt, заглушка
  4. Dockerremnanode, geo-файлы
  5. Тюнинг сетиBBR, буферы, nginx
  6. В панелипрофиль по образцу

Как это работает

Один скрипт, одна нода, любой сервер.

Одна команда

Скрипт сам идёт по шагам и проверяет каждый. Команда meridian на сервере всегда свежая.

Снаружи — обычный сайт

Без нужного пути домен отдаёт страницу-заглушку. Прокси видит только тот, кто знает путь.

Любая локация

Ubuntu 20.04+ или Debian 11+ у любого хостера. Германия, Финляндия, Нидерланды — без разницы.

Возможности

Каждая — отдельный пункт меню и страница в вики.
